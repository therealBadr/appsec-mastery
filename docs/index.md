# AppSec Mastery

**An open application-security curriculum, written in public while I learn it.**
Six stages, 42 project-style subjects, from Linux and networking to mobile, cloud and supply-chain research.
Every lesson, lab write-up and solution here is written by a learner, verified on a real lab, and open to correction.

## How this site works

<div class="grid cards" markdown>

-   **A specification per subject**

    Each of the 42 subjects is written like a 42-school project: a mandatory part, a forbidden list, a bonus, a capstone
    and defense questions. You can follow the specs on their own, with no help from me.

-   **Lessons written while learning**

    When I finish studying a topic I publish the lesson: the mechanism, the commands, the output from my own lab, and
    the mistakes I made. Each lesson says what it was verified on.

-   **Solutions in the open**

    My solutions are public too. The suggested method is to build your own first, then compare. Reading mine first
    defeats the purpose, and [How to use this site](how-to-use.md) explains why.

-   **Progress you can trust**

    The [roadmap](roadmap.md) is computed from what is actually published. Nothing is marked done until the lessons
    and the solution exist.

</div>

## Where to begin

1. Read [How to use this site](how-to-use.md) (five minutes).
2. Open [Stage 0: Foundations Reset](stage-0-foundations-reset/index.md) and pick the first subject.
3. Set up the lab described in the chapter, then work through the subject.
4. If you find an error, please say so: every chapter has a link to report it.

## Being honest about what this is

This is a learner's notebook turned into a curriculum. It is not written by a certified expert, and it will contain
mistakes. Corrections are welcomed and credited. See [About](about.md) for how the material is produced, including
how AI was and was not used, and [Responsible use](ethics.md) for the lab-only rule.
