# Security policy

This repository contains study material and a static-site build, not a running service.

- **Found a secret, private key or personal data committed here?** Please report it privately through GitHub's
  "Report a vulnerability" feature on the Security tab, so it can be removed and rotated.
- **Found a technical error in a lesson that could lead readers into an insecure configuration?** Open a normal issue using the
  "Error report" template.
