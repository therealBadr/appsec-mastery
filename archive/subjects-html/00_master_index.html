Certification Checkpoints

Readiness-gated, never date-gated — buy a certification once its gate is honestly cleared, not to force readiness.

CertCost (confirm current)Gate before buying
eJPT~$249Pass Stage 1 exit gate (Secure Coding Principles and TLS Configuration's DVWA full sweep)
PNPT~$499Pass Stage 3 exit gate / clear Full Penetration Test Methodology and Reporting
OSCP~$1,699Solving novel problems consistently, post-Stage 4 — never to force readiness, only once demonstrated

Skip: CEH (theory-heavy, vendor-driven), CISSP (governance cert, irrelevant at this stage), Security+ (only if a specific employer requires it), GCIH/GSEC (worth it only if an employer pays).

How to Use This Roadmap

Order. Work the stages in sequence — each one's capstone assumes the depth of everything before it. Within Stage 0-2, the subjects are also ordered deliberately; within Stage 3-5, the order is a strong default but more interchangeable once Stage 2 is cleared.

Pace. There are no weeks or months in these documents on purpose — a stage ends when you clear its exit gate, not on a date. See the accompanying weekly-routine document for how to structure study time, labs, CTFs, and note-taking without a rigid calendar dictating when a stage "should" be done.

Portfolio. Every capstone and every practical output in Stage 0-2 is designed to become a GitHub artifact or a writeup. By the end of Stage 2 your GitHub should already read as a stronger portfolio than most junior security applicants'.

Defense. Treat every exit gate literally — if you can't do it without notes, the stage isn't actually done, whatever the calendar says.
